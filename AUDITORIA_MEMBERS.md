## 1. O QUE É O ABYSSBOT?

O **AbyssBot** é um bot de WhatsApp completo com diversas funcionalidades:

| Característica | Descrição |
|---------------|-----------|
| 🤖 **Tipo** | Bot de WhatsApp automatizado |
| 📅 **Versão** | 10.0.6 |
| 🎮 **Jogos** | RPG, Futebol, Casino, Minesweeper |
| 💰 **Economia** | Sistema completo de moedas e level |
| 📥 **Downloads** | TikTok, YouTube, Instagram, Spotify |
| 🎨 **Figurinhas** | Criador de stickers e GIFs |
| 🤖 **IA** | Chatbot com inteligência artificial |
| 🎯 **Rankings** | Rankings aleatórios de brincadeira |
| 🛡️ **Moderação** | Anti-spam, anti-flood, boas-vindas |

### 📝 COMO CRIAR UMA FIGURINHA

1. Envie uma imagem, vídeo ou GIF

**Com texto:**
1. Envie uma imagem
2. Responda com `!attp [seu texto]`

### ❓ Como subir de nível?

- Envie mensagens no grupo
- Use comandos
- Participe de jogos
- Cada ação dá XP

### ❓ Como comprar coisas?

```
1. Verifique seu saldo: !carteira
2. Veja a loja: !loja
3. Compre: !comprar [item]
```

1. Verifique se está em grupo
2. Use o prefixo correto (`!`)
3. Espere alguns segundos
4. Tente novamente
